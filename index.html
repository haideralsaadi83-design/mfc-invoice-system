⚙️ General Settings

These values are applied automatically to every generated invoice.

Note: VAT Amount always stays zero (the tax is applied only through the VAT % field). Changing VAT % instantly recalculates Calculated VAT Amount and Gross Amount for every line item in the preview — Gross Amount = Net Amount × (1 + VAT% / 100).

Target amount check (Step 2): if an invoice has a target Invoice Amount from Step 2, its Net Amount is checked against that target first. If Net Amount already covers it, VAT % (above) is applied normally. If Net Amount falls short — usually because the available quantity is too low — that invoice's VAT % is forced to 0% and its Calculated VAT Amount is set to the exact target amount instead, so it can still be matched manually in the export.
